#  Dynamic Weather Dashboard

An interactive weather dashboard that provides real-time weather updates and a 5-day forecast using *OpenWeatherMap API*.


# *Features"
- Search weather by city 
- Real-time updates 
- 5-day forecast 
- Responsive design 
- Dynamic UI with glassmorphism


# *Technology* 
- HTML5
- CSS3 
- JavaScript (ES6)
- OpenWeatherMap API
